How Custom Parsing Works

Our extraction engine parses the pasted EULA to map clauses into standard categories. This is an evidence-first system:

  • Heuristic Fallback: If no Gemini API key is configured, the engine scans the document for structural keywords (regex keywords, terms, categories) and extracts matching quotes.
  • AI Parser: If a Gemini API key is saved, the system calls Google's LLM to identify, categorize, and capture verbatim clauses, sections, and confidence scores.
  • Audit History: Analyzed fonts are automatically saved to your local database registry for future checks and tracking.
